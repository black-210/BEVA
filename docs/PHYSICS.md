# BEVA Physics Research Layer

BEVA provides numerical building blocks for difficult physics research. It does **not** claim to solve currently unsolved physical problems. New capabilities include N-body dynamics, Poisson PDE iteration, wave propagation, Lorentz kinematics, Klein-Gordon and Schrödinger dispersion, complex quantum-state normalization/expectation values, and dimensional-analysis checks. These are foundations for reproducible experiments and future solvers for many-body quantum systems, nonlinear PDEs, statistical mechanics, and numerical relativity.

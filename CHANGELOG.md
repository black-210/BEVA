# Changelog

## 1.0.0
- Expanded C11 core.
- LLL with configurable reduction parameters and statistics.
- Exact int64 lattice updates with overflow checking.
- GSO, volume, orthogonality defect, nearest-plane and Babai helpers.
- QR, least-squares QR solve, Cholesky and power iteration.
- Number-theory helpers.
- Python ctypes API.
- CMake, CTest and GitHub Actions CI.
